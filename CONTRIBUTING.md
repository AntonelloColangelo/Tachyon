# Contributing to Tachyon

The Tachyon executables are free for individual, non-commercial use and the software remains the property of the author (see [LICENSE](LICENSE)).

* Questions, bug reports and suggestions about Tachyon: write to the Tachyon author through this repository.
* Do not report Tachyon problems to the STAR project (https://github.com/alexdobin/STAR) or to Alexander Dobin: Tachyon is not an official STAR release.
* If you think a problem is also present in the original STAR 2.7.11b, check it with the original STAR first; only then report it to the STAR project, about STAR.
* When you report a problem, attach the Log.out file and the exact command.

The former "Contributing to STAR" guidelines of STAR are in the STAR repository.
